# strscan — дефолтный список подозрительных строк.
#
# Это ОСНОВА, а не готовая база. Скопируйте нужные строки
# в свой strings/bad_commands.txt и дополните под свои задачи.
#
# Формат: одна строка = одна сигнатура. Регистр не важен.
# Пробелы тоже не важны: при поиске всё приводится к нижнему
# регистру и пробелы убираются.
#
# Комментарии начинаются с #. Пустые строки игнорируются.
#
# Секции:
#   [all] — паттерны для всех языков
#   [bat] — только для .bat / .cmd
#   [ps1] — только для .ps1 / .psm1 / .psd1
#   [vbs] — только для .vbs / .vbe
#   [js]  — только для .js / .jse / .wsf / .wsh
#   [hta] — только для .hta
#
# СИНТАКСИС #wide:
#   Паттерны, начинающиеся с '#wide:', ИГНОРИРУЮТСЯ по умолчанию.
#   Это ШИРОКИЕ паттерны — они дают FP на легитимных скриптах
#   (Office, VS Code, PowerShell-модули Microsoft, minified JS).
#   Но также используются зловредами.
#
#   Чтобы включить широкий паттерн — уберите префикс '#wide:':
#       было:  #wide:invoke-expression
#       стало: invoke-expression
#
#   Включайте широкие паттерны, если нужно максимальное покрытие
#   (но будет много FP). Рекомендуется сначала протестировать
#   в узком режиме, потом включать широкие.
#
# ВАЖНО: не включайте в паттерны имена файлов (autorun.bat,
# svchost.bat) и конкретные пути целиком. Имя может быть любым —
# паттерн с именем ломается. Берите ОБЩИЕ части:
#   плохо:  echo open=autorun.bat
#   хорошо: echoopen=
#
# ПРИНЦИП: вместо масок (*, ?) добавляем близкие варианты одного
# паттерна. Например, для самокопирования:
#   copy%0
#   copy/y"%0"
#   copy/y"%self%"
#   xcopy/y"%0"
# Так покрываем разные синтаксисы без regex.
